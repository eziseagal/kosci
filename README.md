# 🎲 Kości – Multiplayer Dice Game

Welcome to **Kości** — a fun and simple *browser-based multiplayer dice game*!  

This project lets up to **10 players** roll virtual dice and play together in a light and social way — no installation required. Just open it in your browser and start rolling! 🎉

🔗 **Play online:** https://eziseagal.github.io/kosci/  
📦 **Code repository:** https://github.com/eziseagal/kosci

---

## 🕹️ Game Overview

Kości is a JavaScript-powered dice game playable in web browsers. It’s designed for *casual fun* and easy access for everyone. You can involve your friends and enjoy a short multiplayer session (up to **ten players**).

Players take turns rolling dice, aiming for high scores and fun interactions.

---

## 🚀 How to Play

1. Open the URL above in any modern web browser (Chrome, Firefox, Safari, Edge).
2. Share your screen or device with your friends so everyone can see the dice rolls.
3. Take turns rolling the dice and track points manually or by agreed rules.
4. Have fun competing with up to **10 players**!

---

## 📌 Features

- 🎮 Browser-based game — no downloads or installations.
- 👥 Up to *10 players* can participate.
- 🎲 Realistic dice rolls using JavaScript.
- 📱 Works on desktop and mobile devices.
- 🧠 Simple rules — easy to learn and play.

---

## 🧰 Technologies Used

This project is built using:

- **HTML** for structure  
- **CSS** for styling  
- **JavaScript** for game logic and browser interaction

No backend or database is used — everything runs locally in your browser.
